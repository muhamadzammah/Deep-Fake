# Deepfake Detection System using EfficientNetB2 and Explainable AI

This repository contains the implementation of a Deepfake Face Detection System developed using EfficientNetB2 with Transfer Learning, Fine-Tuning, Data Augmentation, and Explainable Artificial Intelligence (LIME). The project includes model training, evaluation, and a Flask-based web application for detecting whether a face image is real or fake while providing visual explanations of the prediction.

The repository contains the complete source code, trained models, documentation, and supporting files required to reproduce the research and application. It is intended for academic research, educational purposes, and further development in computer vision and AI-based digital forensics.
